## 一、WPA2 到底是啥

**WPA**（Wi-Fi **P**rotected **A**ccess，Wi-Fi 保护接入）是一个**加密与认证协议族**，用来保护无线数据不被窃听、不被篡改。**WPA2 是这个协议族里的第二版**，也是目前使用最广、大家最熟悉的"Wi-Fi 密码"背后的加密标准。

它管了两件事：

| 职责 | 说明 |
|------|------|
| **认证（Authentication）** | 确认"真的是你"——通过密码校验上网者的身份，防止随便什么人都能进你的网络 |
| **加密（Encryption）** | 让网上传输的数据变成别人**看不懂的密文**，即使被截获也是一堆乱码 |

> 打个比方：WPA2 就像快递柜——想取件你得先**验证身份**（认证），别人就算看到快递柜里有什么，箱门也是**上锁的**（加密），撬开也读不懂里面的信。

## 二、WPA 家族演进：WEP → WPA → WPA2 → WPA3

无线安全标准是一步步"打补丁"演进过来的，每一代都在修复上一代被破解的漏洞：

| 标准 | 加密算法 | 安全性 / 地位 |
|------|----------|--------------|
| **WEP**（远古） | RC4（弱） | 早已被彻底破解，**勿用** |
| **WPA**（第一代） | TKIP | 过渡方案，安全性一般 |
| **WPA2**（第二代） | **AES / CCMP** | **当前主流，推荐** |
| **WPA3**（第三代） | AES / GCMP | 最新，正在逐步普及 |

**核心关键词**：WPA2 用的是 **AES 加密**（配合 CCMP 工作模式），取代了 WPA 的 TKIP 和 WEP 的 RC4，安全性**跨代提升**。

这也是为什么你在路由器里看到"安全类型"选项时：
- ✅ 优先选 **WPA2-PSK (AES)**
- ❌ 不要选 WEP、TKIP、或"自动/混合"这种可能落到弱加密的选项

## 三、WPA2 的两种工作模式

WPA2 根据使用场景分成两种模式，区别在于**密钥怎么管理**：

### ① WPA2-Personal（个人模式，家用/小办公室）

也叫 **WPA2-PSK（Pre-Shared Key，预共享密钥）**。

- 大家共用**同一个 Wi-Fi 密码**（PSK）；
- 设备连接时通过 **四次握手（4-Way Handshake）** 协商出会话密钥；
- 好处是**简单方便**——你只需要记一个密码，这也是家用路由器的**默认形态**。

> 你手上那台家用路由器，你设的那个"Wi-Fi 密码"，通常就是 WPA2-Personal 的 PSK。

### ② WPA2-Enterprise（企业模式，企业/校园网）

对接 **802.1X / RADIUS 服务器**：

- 每个用户有**独立的账号密码**；
- 每个会话**单独认证、密钥互相独立**——一人一密；
- 安全性更高，即使一个账号泄露，也不会影响别人。

> 校园网、企业办公网那种"用学号/工号+密码登录"的 Wi-Fi，多半就是 WPA2-Enterprise。

| 对比项 | WPA2-Personal | WPA2-Enterprise |
|--------|---------------|-----------------|
| 适用场景 | 家庭、小办公室 | 企业、学校等 |
| 认证方式 | 共享密码（PSK） | 802.1X / RADIUS，独立账号 |
| 密钥管理 | 大家一个密钥 | 一人一密，会话隔离 |
| 部署复杂度 | 低，即插即用 | 高，需要认证服务器 |

## 四、加密到底干了啥：明文 vs 密文

无加密和有 WPA2 的最大区别，看同一份数据在空中传输时的"外观"就懂了：

```
❌ 无加密（明文）            ✅ 有 WPA2（密文）
────────────────────       ────────────────────
密码: 123456 · 卡号: 6222    qFn6$#2@9z&vPk...（乱码）
────────────────────       ────────────────────
旁路者一眼就能看光         旁路者看到的只是乱码
极易被窃听、篡改             内容被加密，无法直接读取
```

**WPA2 做的事**就是：在"发送前"把数据加密成乱码，"接收端验证后"再还原。中间即使有人截获数据包，拿到的也只是一堆看不懂的密文。

## 五、实际使用例程：ESP32 用 WPA2 连 Wi-Fi

理论讲完，来一段真实代码——这是 **ESP32 / ESP-IDF** 开发里很典型的"自动连接已保存 Wi-Fi"的逻辑。

### 这段代码在干嘛

1. 从 **NVS（Non-Volatile Storage，非易失存储）** 读回之前保存好的 SSID 和密码；
2. 填进 `wifi_config_t` 结构体；
3. 用 `WIFI_AUTH_WPA2_PSK` 把**最低认证阈值**设为 WPA2；
4. 调 `esp_wifi_set_config` 应用配置；
5. 调 `esp_wifi_connect` 发起连接。

### 关键代码

```c
// 1) 从 NVS 非易失存储读回已保存的 SSID 与密码
nvs_get_str(handle, "wifi_ssid",  (char*)cfg.sta.ssid,  &lenSsid);
nvs_get_str(handle, "wifi_pass",  (char*)cfg.sta.password, &lenPass);

// 2) 关键：把最低认证阈值设为 WPA2-PSK
//    = 只接受 WPA2 及以上安全级别的网络（拒绝 WEP / WPA-psk / OPEN）
cfg.sta.threshold.authmode = WIFI_AUTH_WPA2_PSK;

// 3) 应用配置并连接
ESP_ERROR_CHECK(esp_wifi_set_config(WIFI_IF_STA, &cfg));
ESP_ERROR_CHECK(esp_wifi_connect());

// 4) 连接状态用 LED 反馈（略）
```

### 重点讲解：那一行 `threshold.authmode`

```c
cfg.sta.threshold.authmode = WIFI_AUTH_WPA2_PSK;
```

这是**代码里实际用 WPA2 的开关**。它有 3 个关键理解点：

**（1）它是"阈值"不是"强制指定"**
- ✅ 接受 **WPA2 及以上**安全级别的网络
- ❌ 拒绝**低于 WPA2** 的网络（WPA、WEP、开放网络 OPEN）

| 目标 AP 加密 | 结果 |
|-------------|------|
| WPA2-PSK | ✅ 连接 |
| WPA3-SAE | ✅ 连接（高于阈值） |
| WPA-PSK | ❌ 拒绝（低于阈值） |
| OPEN（开放） | ❌ 拒绝 |

**（2）它对应的是"哪种 WPA2"**
`WPA2_PSK` 指的就是前面讲的 **WPA2-Personal（预共享密钥）** 模式——家用路由器最常见的形态，密钥就是你的 Wi-Fi 密码。

**（3）密码从哪来**
密码从 NVS 读回的 `8~63` 字符预共享密钥。连接时 ESP32 会用它对路由器的认证过程做"握手"，协商出会话密钥，之后数据就按 **AES/CCMP** 加密传输。

### ESP32 支持的完整认证模式枚举

```c
typedef enum {
    WIFI_AUTH_OPEN = 0,        // 开放网络（无密码）
    WIFI_AUTH_WEP,             // WEP（已淘汰，不安全）
    WIFI_AUTH_WPA_PSK,         // WPA-PSK
    WIFI_AUTH_WPA2_PSK,        // ← 我们这里用的
    WIFI_AUTH_WPA_WPA2_PSK,    // WPA/WPA2 混合
    WIFI_AUTH_WPA3_PSK,        // WPA3-SAE
    WIFI_AUTH_WPA2_WPA3_PSK,   // WPA2/WPA3 混合
} wifi_auth_mode_t;
```

### 一个小进阶（可选）

如果你的代码只想接 WPA2 及以上、同时想增强安全，可以进一步开启**受保护的管理帧（PMF）**：

```c
cfg.sta.threshold.authmode = WIFI_AUTH_WPA2_PSK;
cfg.sta.pmf_cfg.capable   = true;   // 支持受保护管理帧
cfg.sta.pmf_cfg.required  = false;  // 不强制（兼容老旧 AP）
```

## 六、总结

| 层面 | 要点 |
|------|------|
| **WPA2 是什么** | Wi-Fi 第二代加密与认证协议，管"认证 + 加密"两件事 |
| **安全级别** | 用 AES/CCMP，跨代取代 WEP 和 WPA 的弱算法 |
| **两种模式** | Personal（家用共享密码）/ Enterprise（企业一人一密） |
| **加密作用** | 数据在传输时变成乱码，截获也读不懂 |
| **实际代码** | 一行 `threshold.authmode = WPA2_PSK` 即可把最低安全设为 WPA2 |

**一句话记住**：路由器选 `WPA2/AES` 最稳妥；代码里设 `WIFI_AUTH_WPA2_PSK` 就是告诉设备"低于 WPA2 的网络我都不连"。
